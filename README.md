### 🚀 Sobre mí

Soy un apasionado del desarrollo de software y la resolución de problemas a través del código. Me especializo en el ecosistema **JavaScript moderno** y en construir arquitecturas backend robustas y eficientes. 

Actualmente trabajo de forma independiente y soy el fundador de **[CDP Studio](https://cdpstudio.es)**, mi propio proyecto para ayudar a startups y empresas a materializar sus ideas en productos digitales reales.

*   💻 **Full-Stack:** Me muevo cómodamente tanto diseñando interfaces en React como estructurando servicios backend con Node.js o Spring Boot.
*   ⚡ **Foco técnico:** Interesado en sistemas en tiempo real, optimización de bases de datos y buenas prácticas de desarrollo.
*   📦 **DevOps de bolsillo:** Automatizo y despliego mis proyectos utilizando Docker para asegurar que todo funcione en cualquier entorno.

### 📂 Proyectos destacados

Aquí tienes acceso directo a mis proyectos reales, donde combino el desarrollo móvil nativo y tecnologías web:

1.  **[FourthWall Library App](https://github.com/CatalinDP/FourthWall-LibraryApp)**
    *   *¿De qué va?* Aplicación móvil nativa para Android. Una biblioteca virtual moderna con una interfaz declarativa y reactiva.
    *   *Stack:* Kotlin, Jetpack Compose, Android SDK.
2.  **[HikingApp Project](https://github.com/CatalinDP/HikingApp-Project)**
    *   *¿De qué va?* Aplicación móvil nativa en Java para explorar y gestionar rutas de senderismo usando componentes clásicos de Android.
    *   *Stack:* Java, Android SDK, XML Layouts.
3.  **[TicTacToe React](https://github.com/CatalinDP/TicTacToe)**
    *   *¿De qué va?* Juego interactivo web para demostrar lógica de componentes y control de estados de juego.
    *   *Stack:* React, JavaScript, CSS3.
